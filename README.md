## アプリの概要

```
┌────────────────────────────────────────────────────────────┐
│                  Entrepreneur App                          │
│                                                            │
│   Discord連携でログイン                                    │
│        ↓                                                   │
│   活動実績を申請 → 管理者が審査 → ポイント獲得            │
│        ↓                                                   │
│   作業時間をDiscordに投稿 → 自動記録 → ポイント獲得       │
│        ↓                                                   │
│   バッジ達成・メンバーと比較・コミュニティ活性化           │
└────────────────────────────────────────────────────────────┘
```

**主な機能:**

| 機能 | 説明 |
|------|------|
| ダッシュボード | 今月の作業時間・直近ログを一覧表示 |
| 活動実績申請 | イベント参加・登壇などの実績を申請 |
| ポイント | 活動・作業時間に応じてポイントを獲得 |
| バッジ | 日数・時間・活動回数の達成バッジを取得 |
| メンバー一覧 | コミュニティメンバーのプロフィールを閲覧 |
| Discord連携 | 審査通知・タイムログ自動解析 |

│  │1週間│ │1ヶ月│ │3ヶ月│ │半年 │ │1年  │            │

### ポイントの計算方法

```
総ポイント = アクティビティポイント + 時間ポイント

アクティビティポイント: 活動実績が承認されるたびに加算
時間ポイント: 総作業時間(時間) × 1pt
```

## Discord連携

### スライド 8: Discord連携の仕組み

```
┌───────────────────────────────────────────────────────────────┐
│  Discord                                                      │
│                                                               │
│  あなた: 「今日は3時間コーディングした！」                     │
│            ↓ Botが自動解析                                    │
│  Bot: タイムログを記録しました (180分)                        │
│                                                               │
│  ダッシュボードに即反映                                       │
└───────────────────────────────────────────────────────────────┘
```

### タイムログの記録方法

Discordの自分のチャンネルに作業時間を含む投稿をするだけで自動記録されます。

**記録される例:**
```
「今日は2時間勉強した」→ 120分記録
「3時間半コーディングした」→ 210分記録
「1.5時間のミーティング」→ 90分記録
```

**記録されない例:**
- 作業時間の数値が含まれていない投稿
- 別のチャンネルへの投稿

### Discord通知の種類

| 通知 | タイミング | 送信先 |
|------|-----------|--------|
| 活動実績申請 | 申請時 | 管理者チャンネル |
| 承認通知 | 管理者が承認時 | あなたのDM |
| 却下通知 | 管理者が却下時 | あなたのDM |
| 自己紹介投稿 | プロフィール保存時 | 自己紹介チャンネル |

## 管理者向け：活動実績の審査

### スライド 9: 審査フロー

```
新規申請
    ↓
管理者チャンネルに通知が届く
┌─────────────────────────────────────────┐
│  活動実績申請                           │
│  申請者: 田中太郎                       │
│  イベント: ハッカソン参加               │
│  日程: 2026-03-20                       │
│  参加者数: 50人                         │
│  URL: https://...                       │
│                                         │
│  [承認する]  [却下する]                 │
└─────────────────────────────────────────┘
    ↓
承認 → ポイント付与 + 申請者にDM通知
却下 → 申請者にDM通知
```

**審査手順:**
1. Discordの管理者チャンネルを確認する
2. 申請内容（イベント名・URL・学びなど）を確認する
3. **「承認する」** または **「却下する」** ボタンをクリックする
4. 申請者に自動でDM通知が送られる

## 開発者向け：セットアップ

### 必要な環境

- Node.js 18以上
- Python 3.13以上
- [uv](https://docs.astral.sh/uv/) (Pythonパッケージマネージャ)
- Discordアプリケーション (Bot Token + OAuth2)

### 1. リポジトリのクローン

```bash
git clone <repository-url>
cd entrepreneur_app
```

### 2. バックエンドのセットアップ

バックエンドのPython環境は [uv](https://docs.astral.sh/uv/) で管理しています。

```bash
cd back

# 依存パッケージのインストール (pyproject.toml / uv.lock から仮想環境を作成)
uv sync

# 環境変数の設定
cp .env.example .env
# .envを編集して各値を設定

# DBマイグレーション
uv run alembic upgrade head

# 開発サーバー起動 (API + Discord Bot)
uv run python -m app.dev_runner
```

> **Tips:**
> - 新しい依存パッケージを追加する場合は `uv add <package>` を実行してください。
> - `uv run <command>` を使うと、仮想環境を都度activateせずにコマンドを実行できます。
> - 仮想環境を直接利用したい場合は `source .venv/bin/activate` でactivateできます。

**.env の設定例 (バックエンド):**
```env
DATABASE_URL=sqlite:///./app.db
DISCORD_BOT_TOKEN=your_bot_token
DISCORD_GUILD_ID=your_guild_id
DISCORD_ADMIN_CHANNEL_ID=your_admin_channel_id
DISCORD_CATEGORY_ID=your_category_id
DISCORD_INTRO_CHANNEL_ID=your_intro_channel_id
INTERNAL_API_SECRET=your_secret
```

### 3. フロントエンドのセットアップ

```bash
cd front

# 依存パッケージのインストール
npm install

# 環境変数の設定
cp .env.example .env
# .envを編集して各値を設定

# 開発サーバー起動
npm run dev
```

**.env の設定例 (フロントエンド):**
```env
AUTH_SECRET=your_auth_secret
AUTH_DISCORD_ID=your_discord_client_id
AUTH_DISCORD_SECRET=your_discord_client_secret
DISCORD_GUILD_ID=your_guild_id
NEXT_PUBLIC_API_URL=http://localhost:8000
INTERNAL_API_SECRET=your_secret
```

### 4. アクセス

| サービス | URL |
|---------|-----|
| フロントエンド | http://localhost:3000 |
| バックエンドAPI | http://localhost:8000 |
| APIドキュメント | http://localhost:8000/docs |

### 技術スタック

| 領域 | 技術 |
|------|------|
| フロントエンド | Next.js (App Router), TypeScript, Tailwind CSS |
| 認証 | NextAuth v5 (Discord OAuth) |
| バックエンド | FastAPI, Python |
| データベース | SQLite + SQLAlchemy + Alembic |
| Discord Bot | discord.py |

## ユーザーフロー全体図

```
[ログイン]
    │ Discord OAuth
    ↓
[ダッシュボード]
    ├─→ [作業時間をDiscordに投稿] → タイムログ自動記録 → ポイント加算
    ├─→ [活動実績を申請] → 管理者審査 → 承認でポイント加算
    ├─→ [ポイント画面] → バッジ確認
    ├─→ [メンバー一覧] → 他メンバーのプロフィール閲覧
    └─→ [プロフィール編集] → 自己紹介チャンネルに自動投稿
```
